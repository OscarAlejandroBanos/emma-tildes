# Emma y el Profesor Don Ganso

Un juego para aprender **acentuación española**. Ocho capítulos, cada uno con su
regla, su jefe y su banco de palabras propio; el último toma exámenes reales de
PAU y de acceso para mayores de 25.

**Jugar:** <https://oscaralejandrobanos.github.io/emma-tildes/>

No pide cuenta, no se instala y **funciona sin conexión**: cada capítulo es un
único archivo HTML que se abre con doble clic.

---

## Cómo se reparte en clase

Que los alumnos entren por el **capítulo suelto** (5 a 16 MB), no por el archivo
completo (66 MB). Treinta a la vez son 250 MB en el wifi del centro contra 2 GB.

| | |
|---|---|
| `cap/1/` … `cap/8/` | cada capítulo por separado |
| `juego/Emma_Juego_Completo.html` | los ocho seguidos, con vidas compartidas y el final |

El archivo completo está para quien quiera la partida entera, y para
descargarlo y jugarlo sin conexión.

## Cómo se juega

Aparece una palabra sin tilde. Se toca la vocal que la lleva —la letra cambia de
glifo y se enciende en oro— y se pulsa **OK**. Si no lleva tilde, OK directamente.

El castigo es asimétrico a propósito: bajo presión el instinto es dar OK a todo,
así que **fallar cuesta un corazón, y ponerle una tilde de más, también**.

Hay un **modo con más tiempo y una vida extra** en la portada de cada capítulo,
para quien necesite pensar sin reloj. No baja el listón: separa a quien sabe la
regla y va lento de quien no la sabe.

## Privacidad

El juego **no pide cuenta, no manda datos a ninguna parte y no necesita wifi**.
Al acabar cada capítulo se puede descargar un informe de los fallos en CSV, y
**no tiene campo de nombre a propósito**: el archivo se lo queda el alumno y lo
entrega él si quiere.
